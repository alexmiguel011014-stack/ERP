# Pasta build/

Coloque aqui o ícone do aplicativo no formato `.ico`.

## Como criar o ícone

1. Prepare uma imagem quadrada (ex: 256x256px) em PNG ou JPG
2. Use um conversor online gratuito como [ConvertICO](https://convertico.com/) ou [RealFavicon](https://realfavicongenerator.net/)
3. Salve o resultado como `icon.ico` nesta pasta

## Estrutura esperada

```
build/
├── icon.ico        ← Ícone do aplicativo (NSIS + atalhos)
└── README.md       ← Este arquivo
```
